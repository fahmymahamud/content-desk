# Avatar poses (optional)

Leave this folder empty for faceless reels with no avatar. That is the default (`avatar:false` in `desk/index.html`).

To show your own character in reels, add transparent PNGs (about 600 px tall) named exactly:

arms-crossed-low-angle, big-grin, celebrating, confused, count-one, determined, exhausted, face-palm, fullbody-pointing, fullbody-wave, jaw-dropped, laughing, mind-blown, peek-over-glasses, pointing-side, proud-tie, sceptical-eyebrow, shushing, smirk-glasses-lowered, thinking, whispering, worried-sweat

(each with `.png` on the end), then set `avatar:true` and `avatarDesc` in the settings block of `desk/index.html`.
Use only a character you own or made yourself.
